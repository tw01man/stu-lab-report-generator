# 实验报告自动生成器

读取实验指导书（docx / pdf / txt / md / doc），自动提取实验目的、设备、原理、步骤、图片和数据表格，填入学校的 Word 模板，一次生成可直接编辑的实验报告。

**工具只整理指导书里已有的内容，绝不编造测量数据和结论。** 实测数据、示波器截图等需要你手工填写的格子会留空并写入灰色提示，生成后由你自己补。

## 核心功能

- **自动解析指导书**：支持 `.docx`、`.pdf`、`.txt`、`.md` 和旧版 `.doc`，自动识别并切分实验一、实验二……各自的内容。
- **过滤指导性板块**：正文不会混入"注意事项 / 预习要求 / 报告要求 / 实验要求"等指导性段落；其中真正的问答题会归入"思考题"。
- **LaTeX 转 Word 原生公式**：识别出的公式转换成 Word 原生公式对象（OMML），在 WPS / Office 中可直接编辑；单独成行的公式居中显示。
- **适配学校 docx 模板**：按模板里原样存在的标题定位，把内容填进对应段落或表格单元格，保留原有字体、字号和版式。
- **表格与图片保留**：指导书里的表格按单元格原样复制，印刷的给定值保留；图片插入报告对应位置。
- **测量格留空**：需要实测的格子保持空白（或写入灰色提示），不会伪造数据或截图。
- **可选 AI 改写**：默认关闭；开启后只把原文改写成报告语言，数值、单位、结论仍以指导书为准。

## 环境要求

- Python 3.10 及以上。
- Windows 上需要安装 WPS 或 Office 才能打开生成结果并手工补填。
- 安装依赖：

```bash
python -m pip install -r requirements.txt
```

## 首次配置

复制两份示例配置，改成本机可用的版本：

```bat
copy templates\模电.example.json templates\模电.json
copy profiles\example.json profiles\profile.json
```

- `templates\模电.json`：把 `template_docx` 改成你的 Word 模板路径。可以写相对于 `templates/` 目录的文件名（如 `实验报告模板.docx`），也可以写绝对路径。
- `profiles\profile.json`：填写 `name`（姓名）、`student_id`（学号）、`department`（院系）、`major`（专业）。

第一次使用请务必先完成这一步，否则程序或双击脚本会提示缺少配置。

## 快速开始

```bash
# 从 docx 指导书生成实验三报告
python -m lab_report --guide "指导书.docx" --experiment 3

# PDF 指导书，指定输出目录
python -m lab_report --guide "指导书.pdf" --experiment 2 --out "输出目录"

# 纯文本指导书
python -m lab_report --guide "实验一.txt"

# 留空实验编号，自动取第一个实验
python -m lab_report --guide "指导书.docx"
```

输出文件名形如 `<学号> <姓名> 实验三 <标题>.docx`（例如 `2023000000 张三 实验三 晶体管单管放大器.docx`），默认放在指导书所在目录。同名文件已存在时会自动加时间戳，**不会覆盖旧报告**。

## 双击使用（.bat）

不需要记命令，双击 `生成报告.bat` 即可：

1. 双击项目根目录下的 `生成报告.bat`，会打开一个命令行窗口。
2. 把实验指导书文件直接**拖进这个窗口**，然后按回车。
3. 按提示输入实验编号（如 `3` 或 `三`），也可以直接留空，留空时取第一个实验。
4. 再按回车，等待程序运行结束。
5. 到指导书所在目录取生成的 `.docx` 报告。

首次运行前必须先完成上面的"首次配置"（`templates\模电.json` 和 `profiles\profile.json`），否则脚本会提示并退出。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| `--guide` | 指导书路径（必填） |
| `--experiment` | 实验编号，如 `3` 或 `实验三`；留空取第一个实验 |
| `--template` | 模板配置 JSON，默认 `templates/模电.json` |
| `--profile` | 个人信息 JSON，默认 `profiles/profile.json` |
| `--out` | 输出目录，默认指导书所在目录 |
| `--tables` | 表格位置：`preserve`（默认，保持原文位置）或 `results`（统一移到"实验结果"区） |
| `--blank` | 手工填写的格子：`placeholder`（默认，写灰色提示）或 `empty`（完全留空） |
| `--ai` | 启用 AI 改写正文（默认关闭） |
| `--ai-config` | AI 配置 JSON，配合 `--ai` 使用 |
| `--open` | 生成后用默认程序打开报告 |
| `--no-validate` | 跳过生成后的自检提示 |

## AI 改写（可选）

默认关闭，不联网。需要改写正文时：

1. 复制 AI 配置示例：

   ```bat
   copy profiles\ai.json.example profiles\ai.json
   ```

2. 按需修改 `provider`（`anthropic` 或 `openai`）、`model`、`base_url`、`api_key_env`。
3. 把 API 密钥放进环境变量（默认变量名为 `ANTHROPIC_API_KEY`）：

   ```bat
   set ANTHROPIC_API_KEY=你的密钥
   ```

   **密钥只放在环境变量里，不要写进任何 JSON 或代码。**
4. 运行时启用：

   ```bash
   python -m lab_report --guide "指导书.docx" --experiment 3 --ai --ai-config profiles/ai.json
   ```

启用后，指导书正文会发送给所配置的服务商。AI 被限制为只能改写原文、保留所有数值和单位、不添加书外知识；API 不可用时自动退回原文整理，报告仍会正常生成。

## 换课程 / 换模板

1. 复制示例模板配置，例如 `templates/模电.example.json` → `templates/电路分析.json`。
2. 修改 `template_docx` 指向新课程的 Word 模板（相对路径按 `templates/` 目录解析，也可写绝对路径）。
3. 修改 `anchors`：每个章节写模板里**原样存在的标题文字**，并说明内容填到 `next_paragraph` 还是 `next_table` 的第几个单元格。
4. 若模板里有独立的 `《课程名》` 标题行和 `《课程名》课程大纲评分标准：`，可设置 `"blank_course_title": true`，生成时把课程名清空为 `《》`（保留原格式），方便按不同科目手填。
5. 运行时加 `--template templates/电路分析.json`。

新增个人信息：复制 `profiles/example.json`，修改 `name` / `student_id` / `department` / `major`，用 `--profile` 指定。

## 隐私与边界

- **不编造数据**：只整理指导书里已有的内容，不虚构测量数据、波形和结论；需要实测的格子留空或写提示。
- **不覆盖旧报告**：同名输出文件会自动加时间戳，原报告始终保留。
- **仓库只放代码和示例**：真实的个人信息配置（`profiles/profile.json`）、AI 配置（`profiles/ai.json`）、本机 Word 模板、课程指导书和生成的报告都不进仓库，已在 `.gitignore` 中排除。
- **密钥不进仓库**：API 密钥只通过环境变量传入，配置文件中只保存环境变量名。

## 常见问题

- **提示找不到模板章节**：模板标题被改过，或 `anchors` 里的文字与模板不一致；按模板里实际标题更新 JSON。
- **保存失败 / Permission denied**：报告正在 WPS 或 Office 中打开，关掉后重试。
- **PDF 提示"没有文字层（可能是扫描件）"**：扫描件暂不支持 OCR，请提供带文字层的 PDF 或 Word 原稿。
- **生成的报告有"校验：N 个提示"**：例如某张图在指导书里没有题注，需要你手工补；报告仍会生成，提示仅供参考。
- **页眉校验不匹配**：`lab_report/validate.py` 的页眉校验按"汕头大学实验报告"编写，换到其他学校使用时请按自己的页眉文字调整校验逻辑。
